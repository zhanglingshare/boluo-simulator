# 今天，博罗有戏！｜第一季可玩原型

**独立游戏实验区**：https://zhanglingshare.github.io/boluo-simulator/life-game/

## 本版包含

- 罗阳生活圈的示意地图（虚构街区，不对应真实地理位置）
- 8名虚构角色、稳定人物档案和关系
- 7个连续章节：街角小集试运营
- 3种玩家身份
- 每章3条可调查线索，每天最多揭开1条
- 每章3个决策选项，改变预算、信任、人气、团队精力和线索进度
- 人物互动、角色关系、章节进度、结局计算
- 浏览器本地保存、重玩和分享结局
- V11与Lab-2032跳转入口

## 诚实边界

人物、对话、剧情、街区、经营数字和结局均为虚构游戏内容。不是居民访谈、市场调查或博罗真实经营数据。游戏中的“七天”是七个章节，不要求现实等待七天。

第一版为**规则驱动的本地剧情原型**，不调用大模型，不需要 API Key，不会把虚构角色对话写入真实证据库。实时AI对话、每日内容生成、多人共享状态和全服事件属于后续阶段。

## 技术

纯静态 HTML / CSS / JavaScript + JSON。所有进度保存在当前浏览器 localStorage。无外部运行时依赖、无浏览器密钥、无后端服务。

## 本地运行

建议使用静态 HTTP 服务打开目录，避免 file 协议对 JSON fetch 的限制：

    python3 -m http.server 8000

然后访问 http://localhost:8000/life-game/。

## 迭代原则

- 不修改 V11 原有页面和 Lab-2032 工作区。
- 新增游戏功能必须保持事实与虚构剧情分离。
- AI可以负责表达和人物互动，游戏状态数值必须由明确规则计算。
- 未来接入每日NPC内容时，必须通过结构校验、事实引用校验和失败兜底。
