# UTEK ONE V15: 企业能力进化实验室

> 研发概念版。**全部案例、运行记录、质量指标、成本、网络和效果均为合成数据**，不代表宇泰真实经营。不会连接真实设备或企业系统。

## 体验

打开 `index.html`（本地需保持 `assets/`, `data/`, `kernel/` 同层），或者打开独立的 `demo.html`（已经内嵌全部资源，可直接双击）。

1. 选择六个经典问题之一：机房异常、研发返工、质量复发、交付阻塞、知识断层、能耗异常。
2. 点击「让 AI 团队处理一次」，增加真实可复算的**合成事件**，观察六维、置信区间、事件链、三路对照的变化。
3. 点击「继续下一步」看任务接力；切换专业细节查看适配、风险与指标；点击「导出记录」下载 JSON。

## 设计纪律

- 词元是一项可调用的专业能力；执行契约是运行形态，不是定义。
- 六维来自事件记录，含样本量与 Wilson 置信区间。没有让人手填 4.5 分。
- 执行权限由最低维、样本量、事故等条件约束，不能靠均分提高放权。
- 七阶成长漏斗来自记录中的 `experience/captured/draft/shadow/authorization/mature/reuse` 事件；`mature` 代表**演示算法门槛通过**，绝不是现实审核通过。
- 同一案例的词元、大模型、人工对照是**模型生成的反事实情景**，尚非真实 A/B 测试；需要真实业务数据才能验证。
- 记录是浏览器内存里的只追加数组 + 非密码学链式校验。**不具备生产环境不可篡改审计或多用户持久化能力**。
- 小宇采用 3D 风格渲染图与 CSS 轻动画，不是实时 WebGL 骨骼数字人。语音依赖浏览器语音合成支持。

## 文件结构

- `kernel/engine.js`: 合成事件、统计、治理门槛、成长漏斗、对照模型、账本校验。
- `data/scenarios.js`: 六个典型问题及假设参数。
- `assets/xiaoyu.png`: 3D 风格小宇渲染图。
- `tests/test-engine.js`: 内核自动测试。
- `tests/test-ui.py`: Chromium UI 测试脚本（浏览器被环境管理策略阻止时不可执行）。
- `index.html`: 模块化应用入口。
- `demo.html`: 完全独立的离线体验文件。
