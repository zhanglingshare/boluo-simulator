## 三、使用说明

- **深链接接力**：`?entity=<id>` 参数在 holo-single / network 之间互通；v9 侧如使用相同 id 可直接透传。
- **新增实体**：先在 `data/industry-graph.json` 登记（若属于产业网络视图），再在 v9 证据库登记，两边 id 保持一致。
- **v9 独有节点**（如储能电站、新投产项目）目前只存在于变化证据体系；如需进入产业网络视图，按上一条补充登记。
- 本映射表由脚本自动生成，重新生成命令见仓库根 `scripts/`（如有）。
