# 博罗公开数据质量与发布原则

## 公开更新

新闻与生活信息可以按时检查；统计指标仅在有正式可核验发布时更新；实体关系只有在出现新证据后更新。发布内容需标注时间和适用范围。

## 核验边界

- 公开事件与项目公告不自动证明真实经济影响。
- 签约、开工、投产、达产和真实交易需分别确认。
- 缺失数据保持未知，不用零值或未经说明的估算替代。
- 政府规划目标与实际完成数据必须区分。
- 场景输出应明确为特定条件下的结果，不能伪称经验证的概率。

## 发布安全

公开网站应当只读取经过审查的公开数据与展示结果。内部分析策略、权重、参数推导及私有计算代码不得进入公开发布包。公开数据更新和模型版本升级分别评审。

每次发布应能够识别数据版本、生成日期与重要限制；异常时应保持上一次已通过质量检查的公开版本。具体研发和审核工作流由受限环境维护。
