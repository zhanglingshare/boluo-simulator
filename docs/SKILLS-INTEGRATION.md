# 公开数据更新接口说明

本文件仅描述公开网站如何消费已核验的数据，不提供内部数据采集策略、研究方法、计算权重或审核人员操作细节。

## 公开资产

- `hot.json`：已发布的话题与事件线索。
- `life.json`：具有明确更新时间的镇街与生活信息。
- `data/relationship-evidence-v1.json`：已发布的实体与关系观察。
- `data/relationship-changes-v1.json`：可公开的关系变化与显示顺序。
- `data/relationship-sources-v1.json`：来源登记。
- `v11/`：前端页面及其只读数据接口。

上述公开资产不应包含内部评分权重、用于生成情景的私有参数、未公开交易记录、完整研究备忘录。

## 发布约束

每个事实保留来源、时期、对象与核验状态；候选事件不得自动升级为经过证实的关系。新报道不自动改变预测或参数。数据更新应当可追溯，页面显示缺失情况时不得补造数字。

重新发布前检查JSON、页面依赖、桌面端和移动端。详细的采集、校准、候选筛选及内部审核流程应由受限的内部工作环境维护，不在公开仓库书写。
