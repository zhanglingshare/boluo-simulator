# 博罗数据资产 · 统一数据字典（DATA DICTIONARY）

> 适用范围：原版产业风洞（根目录）、决策沙盘（v2/）、全息探索（experiments/holo-single/）。
> 三个产品共用同一套数据资产，本字典是它们理解节点、关系、证据与情景的唯一权威口径。
> 维护：张凌博士（人工审核）；版本：data-dict/1（2026-10-28）。

---

## 一、统一证据等级（Evidence Grade）

历史上四个页面各自用 A/B/C/D 表达过不同含义（见第四节映射）。现统一为四档：

| 等级 | 名称 | 含义 | 视觉处理 |
|---|---|---|---|
| **A** | 直接观测 | 官方统计、政府文件、可核验主体数据，带真实 URL 与时期 | 关系用**实线**；数值直接呈现 |
| **B** | 交叉推断 | 多源间接证据 + 结构系数/行业常识推算，**只给区间**，不冒充置信区间 | 关系用**虚线**（行业常识）或**点线**（单源新闻、最弱） |
| **C** | 假设探索 | 用户情景或模型校准参数，用于观察结构变化，**不代表现实、不覆盖事实** | 不构成真实关系；以"情景"形式存在 |
| **D** | 未知 | 证据不足，不编造；列入数据缺口，注明需要什么才能收紧 | **不连线、不造数** |

**C 级的两个子类（都是假设，不覆盖事实）**：
- `C.user`：用户在前端选择的情景（如低/中/高跨界联系）。
- `C.calibrated`：经人工审核的模型校准参数（见 evidence/ 与 params.json）。

**关键纪律**：
- A/B/D 描述**事实**（观测 / 推断 / 未知）；C 描述**假设**。
- 真实关系只有 A/B 两级；C 不连真实边，D 不连线。
- 推断不了的给 D，不用零值或假数字填充。

## 二、核心实体定义

| 实体 | 字段 | 说明 |
|---|---|---|
| **Node（节点）** | `id, name, type, town, cluster, desc, state` | 27 个产业/生态/外部节点，三版本 id 完全对齐 |
| **TownAnchor（镇街锚点）** | `id(town:名), name, type(街道/镇)` | 跨层导航锚点，16 个；不代表实际人流物流 |
| **Edge（关系）** | `id, source, target, level(A/B), kind, detail, weak?` | 真实关系；`weak=true` 的 B 级用点线（单源弱证据） |
| **Flow（流场）** | `id, value(null), range{low,mid,high}, method, sources, scenarios` | B 级区间，永不写死单值 |
| **Event（事件）** | `id, title, url, event_date, locations, verified_status` | 今日动态；归属不确定则保持未定位 |
| **Scenario（情景）** | `key, name, params` | C 级假设；沙盘 5 情景、M3 双世界 |

**节点类型 type**：`chain`（链主）、`giant`（小巨人）、`capillary`（配套群落）、`old`（老厂）、`agri`（农品地标）、`eco`（生态）、`ext`（外部城市）。

**关系类型 kind**：`供应链`、`环保约束`、`资源竞争`、`生态与文旅`、`同镇关联`。

## 三、三版本定位与数据口径

| 产品（对用户命名） | 回答的问题 | 证据使用 | 数据口径 |
|---|---|---|---|
| **看见博罗（全息探索）** EXPLORE | 发现了什么？哪些联系不易被看见？ | 边 A/B 分级、流场 B 区间、M3 情景 C | 星群/关系/事件，只读不写 |
| **博罗决策沙盘（风洞2.0）** LEARN | 为什么值得关注？怎样形成判断？ | 5 情景均为 C 级假设，结果标注非预测 | 七幕教学，用户假设私有 |
| **博罗产业风洞（原版）** ANALYZE | 经得起什么检验？证据与稳健性？ | A 级事实 + B 级区间 + C 级校准参数 | 模型/压测/来源，参数经审核门 |

**科学边界**：全息网络的结构联系 ≠ 已证实导致宏观经济变化；进入沙盘/风洞引入的新假设必须显式说明，不做无缝因果包装。

## 四、历史标签 → 统一字典映射（消除冲突）

| 来源 | 历史标签 | 原含义 | 统一后 |
|---|---|---|---|
| network 边 / 全息 grade | A | 强证据·官方 | **A**（实线） |
| network 边 / 全息 grade | B | 行业常识推算 | **B**（虚线） |
| network 边（广州-罗浮山国药） | C | 单源新闻·不确定 | **B + weak**（点线） |
| network 冲击按钮 | A/B/C/D | 四个冲击情景编号 | **去字母**，改语义名（data-shock 本就是节点 id） |
| atlas evidence_legend | A/B/C/D | 观测/推断/假设/未知 | 与统一字典**一致**（权威来源） |
| evidence 事件库 | A/B/C/D | 官方/间接/模型校准/未验证 | A/B/D 一致；其 C 归入 **C.calibrated** |

**统一后，"C" 全局只表示"假设探索"，"D" 全局只表示"未知/缺口"**，不再有情景编号或弱证据含义。

## 五、数字口径（做门户/卡片时必须遵守）

- GDP 2025 = **1005.45 亿**（统计公报，A）；2030 目标 = **1600 亿**（政府工作报告，A）。
- 2026 年 1–8 月：规上工业增加值 **+8.9%**；工业投资 **−46.7%**（A，统计口径）。
- **固投 ≠ 工业投资**：用户曾举例"固投 −18.8%"，与现网"工业投资 −46.7%"口径不同，首页反差数字须以官方口径核实，禁止混用。
- 跨界通勤（园洲—东莞）为 B 级区间约 **4500–17000 人次/日**，非实测、非置信区间。
- 所有 B 级数字标"区间/估算"；不写阅读、点赞等后台数字。

## 六、变更本字典

字典本身是"慢本体"，只有出现新核实的定义冲突或官方口径变化时才升版本（data-dict/1 → /2），并在变更记录里写明影响哪些页面。
