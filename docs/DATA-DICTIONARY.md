# 博罗公开数据字段说明

此文件只说明公众能理解的字段含义，并非内部研究变量字典。

- **observation**：已公布的统计观察，需具备期间、统计对象、单位、来源与修订状态。
- **source**：可以核对的来源链接、机构、发布时间。
- **entity**：公开可辨识的企业、项目、园区、镇街等主体。
- **relation**：有证据的实体联系或明确说明为待核实的候选联系。
- **event**：具有可辨识发生时间或报道时间的变化。
- **scenario**：用于对比的假设条件，不是已发生事实。
- **result**：特定数据版本与情景条件下的输出。

## 数据标识

公开数据可以使用直接可核验、间接推断、情景假设、未知等标识，但不得以不确定的关系或推断替代真实交易数据。推断范围不是统计置信区间，除非具备相应估计依据。

不同年度修订值、2026年1—8月与1—9月等不同时期必须分别保存。工业投资、固定资产投资、工业总产值、工业增加值和GDP的统计定义不同。

内部映射、具体假设生成规则、校准系数和模型选择方法不属于本公共字段说明。
