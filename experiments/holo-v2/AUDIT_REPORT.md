## 二、自动化测试（npm test）

`node --test tests/holo.test.js` —— **23 项全过 / 0 失败**。关键断言：

- 数据自检 0 错误，统计 27/30、A12/B17/C1、供应链19/环保3/资源2/生态6、五群 11/2/3/7/4；
- 节点 id 唯一、边端点齐全、同端点不同关系类型合法（htd–lq）、孤立 xc/sb 如实保留；
- 所有边 `weightType=structural`、`direction=undirected`，w 仅 1..5（**关系≠流量**）；
- `FLOWS=[]`，缺数据不生成默认值；观测含统计期/口径/来源；**县级工业投资 −46.7% 不下分镇**；
- 布局同 seed 逐字段相等、不同 seed 有差异、五群锚点最小间距 ≥12；
- 不确定性低→中→高单调、同参全等、恒带 `isHypothesis`/`dimensionless-demo` 不伪装真实；
- 双世界：稳健节点 4（sz,mj,zw,jq）、依赖假设节点 4（lq,ddc,dg,htd）。

## 四、本轮修复的关键缺陷（避免回归）

1. 搜索 `ReferenceError: clear is not defined`（controls.js 缺本地 `clear`）→ 已修，搜索全端可用。
2. 镜头动画单位错配（dt 秒 / duration 毫秒，动画约 22 分钟）→ 统一为秒（flyTo 1.1/1.3/0.85）。
3. 手机竖屏全景裁切 → 相机按 `aspect<0.75` 切换 MOBILE_POSES。
4. 引导态红色环保线斜穿产业簇 → 引导态仅产业/外部核心边正常，其余 dim。
