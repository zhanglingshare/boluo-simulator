# 系统架构｜M1 独立原型

```text
原版公开资料（network.html / life.json / hot.json / who.html）
                     │ 快照摘录
             src/data.js
     Node / Edge / Town / Topic / Cluster
                     │
             src/engine.js
     固定布局 · 证据筛选 · 邻域查询
   B/C假设权重 · 加权度 · 不确定性场景
                     │
              src/app.js
  WebGL2点精灵 · 投影 · 连线 · 相机 · 鼠标/触摸
       UI状态 · 详情面板 · 场景切换
                     │
             index.html + CSS
        PC全屏 + 手机抽屉/类别切换
```

## 数据区分
1. 事实/条目：来自原版公开资料的主体名称、镇街主题、统计指标。统计时间和证据级别沿用原版。
2. 已有关系：原版 `rawEdges`，可点击追踪。A级仅表示原版等级标记，不代表每条直接采购关系都已独立核实。
3. 推断联系：B/C级原版关系以不同线型呈现；假设权重仅用于可视化敏感性实验。
4. 未知真实流量：不构造人口OD矩阵，不把真实人流/物流光强伪装成已知事实。
5. 视觉布置：节点位置仅为稳定呈现结构的布局，不具有地图语义。

## M1范围
- 五组入口、3D观察、园洲产业主体及联系、节点详情、证据筛选、流动数据缺口提示。
- 输入假设 u 后，纯函数 `compute(u, grade)` 重算边权、加权度和节点位置。
- 东莞、深圳、广州、惠州主城等外部节点来自原版公开网络。
