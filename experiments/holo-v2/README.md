# 看见博罗 V2 · 县域全息数据宇宙（M1 实验原型）

> 把博罗的产业、城镇功能、生活活动、文旅农业与外部联系，组织成一个由**节点、关系、流动、状态、时间**组成的可探索全息数据空间。
>
> **M1 里程碑：可操作的「园洲产业星群」全息样板。** 不是真实地理地图，也不是指标驾驶舱；深色全息 3D 数据星群，五大星群、点进产业完成完整六操作。

- 产品定义：县域全息关系与流动图谱（关系结构，非土地复刻）
- 技术：原生 ES Modules + three.js r128（本地），无构建链、无后端、可离线
- 数据：27 节点 / 30 关系（源自原版 `network.html`）/ 11 条 A 级观测；**流量数据有意为空**
- 状态：M1 本地原型，**未提交、未部署、未上线**，位于独立分支 `experiment/holo-v2` 的 `experiments/holo-v2/`

## 一、运行（本地预览）

无需安装任何依赖（three 已内置在 `vendor/`）。在本目录下：

```bash
cd experiments/holo-v2
npm run serve          # 等价于 python3 -m http.server 8765
# 浏览器打开 http://localhost:8765/
```

> 必须经 http 服务打开（ES Modules 不支持 file:// 直开）。
> 手机验证：让手机与电脑同网，访问 `http://<电脑局域网IP>:8765/`，或用 DevTools 设备模拟（390×844）。

## 四、M1 六操作（验收路径）

1. **进入**：全景五群 → 点产业星群，镜头平滑靠近（约 1.1s）。
2. **展开**：产业簇布局插值展开为 11 个主体 + 外部四城（不是弹列表）。
3. **选择**：点园洲链主（如欣旺达 xwd），一度邻居高亮、其余降亮。
4. **追踪**：点边/对端节点，查看关系内容、A/B/C 证据等级与来源；可切等级过滤。
5. **切换观察层**：不丢失选择的情况下切到生活 / 外部联系层。
6. **返回**：一键回全景，位置与状态连续，不重新随机排布。

同时支持：鼠标（旋转/平移/缩放/点击/悬停）、触控（单指旋转、双指缩放）、搜索（如搜"东莞"）；WebGL 不可用自动降级为 2D 关系图。

## 六、数据与科学纪律

- 三种线严禁混用：**关系线**（M1 全部，无方向无数量）/ 流向线（M2）/ 流量线（M3）。
- 关系权重 `w` 是结构强度，**不是**人/货/资金量；没有可核验流量时 `FLOWS=[]`，不造数。
- 四级数据体系：A 直接观测 / B 交叉推断 / C 待核实 / D 未知（D 以空心呈现，不以光效补齐）。
- 不确定性引擎 M1 仅交付**无量纲、明确标注演示**的纯函数，不输出"每天 X 万人通勤"。
- 县级指标（如工业投资 −46.7%）禁止下分到无数据镇街。
