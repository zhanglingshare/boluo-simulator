# 看见博罗 V2 · 全息数据宇宙 M1

独立全息探索原型。此目录不覆盖原版或现有 `/v2/`。

## 运行
打开 `index.html`。若浏览器限制本地脚本，进入本目录执行：
```bash
python3 -m http.server 8000
```
然后访问 `http://localhost:8000/experiments/holo-v2/`（如果从仓库根目录启动），或在本目录启动后访问 `http://localhost:8000/`。

## 交互
- 五个抽象星群：产业制造、城镇生活、山水文旅、农业乡村、外部联系。
- 点击星群展开，选择节点沿现有关系追踪。
- 证据等级筛选沿用原版 A/B/C 标签。
- “未知实验”调整 B/C 关系的假设权重，重算加权网络值与布局。
- 流动观察会说明缺少真实OD数据，不将关系线冒充人流或物流。

## 数据边界
- 数据快照：2026-10-21 07:27，不是实时数据。
- 27个主体、30条关系、12条镇街专题来自原版公开仓库数据快照。
- 原版 A/B/C 标签沿用，未在此原型中重新独立核验。
- 五个星群位置是编辑布局，不是经纬度或真实地理距离。
- 未知实验是人为设定的抽象权重映射，不是可信区间、真实概率或经济影响估计。
- 暂无足以重建镇际通勤、游客来源地或货运量的完整OD数据。

```bash
node tests/verify.mjs

```
DOM烟雾测试不替代真实浏览器的WebGL、触控和手机实测。当前尚需进行真实浏览器视觉验收。
