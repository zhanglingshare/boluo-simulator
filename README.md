## 核心视角

博罗不是一个孤立的县。它连得最紧的那根线，不是连到自己县城，是连到东莞。这不是问题——这是它在大湾区里的位置。

博罗真正该想的不是"钱为什么没留在本地"，而是：**在大湾区网络里，博罗除了产业承接，还能扮演什么角色？**

## 模型边界

- 不是预测器——不预测博罗2030年具体是多少亿
- 所有模拟结果为"在当前假设参数下的参考区间"
- 网络结构和路径系数含假设成分，可改参数复跑
- 不说"导致"，只说"关联/同步/结构提示"
