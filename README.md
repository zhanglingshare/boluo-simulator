# 博罗决策风洞 · V11

这是一个以博罗公开信息为起点的交互式决策实验网站。浏览者可以对照现实变化、观察产业关系、调整条件、比较可能结果，并发现需要进一步核实的问题。

**[进入博罗V11](https://zhanglingshare.github.io/boluo-simulator/v11/index.html)**

## 使用边界

- 官方统计、规划目标、媒体线索、情景结果不能混为同一个事实类别。
- 可调结果只代表给定条件下的实验输出，不是预测承诺，也不代表已经证实的因果效应。
- 未经核实的企业交易、人员流动、项目达产情况应保留未知。
- 页面数据注明统计时期、适用范围和更新状态；用户应结合实际情况继续核对。
