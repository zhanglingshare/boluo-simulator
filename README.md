这是一个面向县域治理的**开源决策模拟演示项目（Demo）**，以广东省惠州市**博罗县**为样本。2025 年博罗成为广东首个 GDP 破千亿的县，西接东莞、赣深高铁半小时到深圳，罗浮山年迎千万客流，还保留着完整的特色农业板块。项目把这些真实公开线索组织成“区位—产业—文旅—农业—人”的耦合网络，通过感知、建构、盘点、推演、压测与反思，尝试回答一个朴素的问题：

**当一个县同时挨着东莞与深圳两个万亿级城市，它最该用好的，究竟是哪几张牌？如果某个变量变了，又会怎样？**

- 在线体验（GitHub Pages）：<https://zhanglingshare.github.io/boluo-simulator/>
- 类型：可直接在浏览器运行的网页（HTML + CSS + JavaScript + ECharts）
- 费用：完全免费，无需注册、无需安装、无需联网授权

这是「风洞系列”的县域样本之一：大亚湾（物的管廊）→ 仲恺（企业链）→ 惠城（人—产业—城）→ **博罗（在大湾区网络里占位置）** → 龙门（山城留住“一张床”）。

## 一、它是什么，不是什么

**它是：**
- 一台把“不确定性”整理成“可看清、可核对结构”的思维工具；
- 一次在公开数据与明确假设之下，对县域未来进行的**压力测试**；
- 一种“先推演、后决策”工作方式的具体示范。

**它不是：**
- 不是对未来的精确预测，不预测具体产值或招商成败；
- 不是因果神谕，不轻易使用“因为 A 所以 B”；
- 不构成任何投资建议，也不替代官方决策。

风洞不替人做决定，它只负责把“看不见的未来”，提前跑给你看。

## 三、核心观点（Demo 版的几点提示）

1. 博罗最大的底牌不是千亿这个结果，而是它的“**坐标**”：约 20 分钟到东莞石龙、赣深高铁约半小时到深圳、罗浮山年迎上千万广深客流——这是地图上才看得见、排名表里看不见的资产。
2. **跌得最响的，未必是对全局传导最强的**：房地产投资 −47.6%、固定资产投资 −18.8%，但规上工业增加值仍 +8.7%——眼前增长主要靠前几年项目陆续投产释放产能，是“换挡节奏”，不是崩盘。
3. 同一套模型跑很多遍，最敏感的不是房价、也不是外贸，而是**新投产项目的节奏**：投产延后，达标比例会明显下台阶；2026 年已签约四宗链主级项目、约 80 亿投资，关键在能否按时投产把下一档增长接上。
4. 文旅正在补“**过夜**”这一课：罗浮山假期过夜游客同比增长约 62%，山野民宿更受青睐；而人均消费约 500 元，把已经进门的人多留半天、多消费一笔，杠杆往往大于再去多拉新游客。
5. **农业是战略底盘，不是落后的尾巴**：一产约 107 亿、增速领先，柏塘山茶、福田菜心、观音阁花生油、博罗红薯等是国家地理标志与区域公用品牌，连着近 40 万农村人口的生计，也连着大湾区的“菜篮子”“茶罐子”。
6. 博罗不需要成为第二个惠城，也不需要成为第二个东莞：**大湾区需要的不是每个地方长成一个样，而是各占一个别人替代不了的位置**——先进制造配套 + 罗浮山文旅康养 + 特色农业 + 通道节点，分工不同，不是高低之分。

> 以上均为“结构提示 / 关联 / 同步变化”，不是因果断言，更不是定论。

## 四、数据来源与分级

本项目数据**全部来自公开渠道**，并按可信度分为四级，报告中可逐项追溯：

- **A · 实测**：统计公报、政府工作报告、计划执行报告、民生实事中直接给出的数字；
- **B · 推估**：部分历史序列按公开增速回推；
- **C · 代理**：镇街级供给代理（如人口密度、是否点名、项目位置），非逐镇街实查；
- **D · 假设**：网络边权重、路径贡献区间等。

主要公开来源包括：博罗县人民政府门户网站、统计公报与计划执行报告、文旅与农业农村公开信息、南方+/惠州日报等媒体，以及微博/抖音/头条等公开热榜。

**数据时效性说明：** 2025 年数据为快报或公报口径，2026 年统计公报发布后部分数字可能微调。今日话题与各镇页**不展示平台后台真实阅读、转发、点赞与“想去”人数**（公开渠道无法获得），改用“关注档（高/较高/中）”与“人气档（高/较高/中）”，并标注数据更新时间；农品按当月真实时令呈现，非当季不出现。

我们坚持：**可以讨论参数，但不能杜撰数据**；看到一个数字，应能知道它究竟是事实、推估，还是假设。

## 五、模型边界（请务必阅读）

1. **不是预测器**：只在一组公开数据与明确假设下给出叙事分布与结构提示；
2. **不做因果断言**：单一地区、有限时间序列的汇总数据，不足以支撑严格因果结论；
3. **反事实不可验证，但参数可核对**：“项目晚两年会怎样”无法重演，但每个参数都能回到公开资料核对；
4. **网络为作者据公开主体构建**，边权重含假设，不等同于真实交易数据；
5. **不构成投资建议**，亦不替代任何官方决策，结论随假设改变而改变。

需要特别厘清口径：GDP、规上工业总产值、规上工业增加值与旅游收入分属不同统计口径，不直接相加；“参考目标”用于情景推演，并非已确定的增长路径。

## 六、技术细节与可复现性

- 全部为静态 HTML + 原生 JavaScript + ECharts，无后端、无数据库；统一计算内核集中在 `model.js`，未来、风洞、报告与五条路页面共用同一套口径。
- 随机数使用 **mulberry32 固定种子伪随机生成器**：相同种子、相同参数、相同次数必复现同一结果；默认种子 42，可自行修改以检验稳健性。
- 五条路径均以均值 μ 与波动 σ 描述，叠加加性全局噪声；五条路的贡献用**同种子成对对照**（仅关闭该条，比较中位数差）得到，**不把五个数字直接相加，也不把覆盖率当作完成率**。
- 数据血统 A/B/C/D 分级，网络主体与关系可溯源；农产品按当月真实时令切换，播种/育苗品类（如秋季的福田菜心）单独标注、不计为上市。

## 七、为什么做这件事

县域的每一个重大决策，最终都落在具体的人身上——园洲、石湾厂里的工人，长宁、横河开民宿与小店的经营者，杨村、观音阁种果榨油的农户。投进去的是真金白银，一旦走偏，代价不小，也很难回头。

这与国家方向一致：“十四五”规划与 2035 年远景目标提出“**加快构建数字技术辅助政府决策机制**”“**探索建设数字孪生城市**”，《数字中国建设整体布局规划》也要求发展高效协同的数字政务；在世界范围内，新加坡（Virtual Singapore）、日本（Project PLATEAU）、英国（What Works Centre）等也在区域决策中采用“先算后干”的方法。这个小小的 Demo，是把上述理念落到一个千亿县的、具体而微的一次尝试。
