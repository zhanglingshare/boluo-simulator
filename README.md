# 博罗县产业决策风洞

> 广东首个千亿县，在大湾区网络里是什么位置？

基于城市计算与复杂网络的区域决策风洞，以广东省惠州市博罗县为样本。
不是预测器，不是数据大屏，不是PPT——是一台把不确定性变成可拍板结构的机器。

## 数据来源

全部来自公开官方渠道：
- 博罗县统计局《2025年博罗国民经济和社会发展统计公报》
- 博罗县政府工作报告、镇街公开信息
- 惠州政府网、南方+等公开报道

## 核心数据（2025年）

- GDP：1005.45亿元，+5.5%（广东首个千亿县）
- 三次产业结构：10.7 : 54.6 : 34.7
- 规上工业增加值：+8.7%
- 社消零：296.99亿，+3.9%
- 固定资产投资：-18.8%
- 常住人口：123.94万，城镇化率60.19%
- 年游客：1028.09万人次，旅游收入51.88亿
- 2030目标：GDP 1600亿

## 方法论边界

- 不是预测器，不预测博罗2030年具体数字
- 所有模拟结果均为"在当前假设参数下的参考区间"
- 网络结构由作者根据公开主体与关系构建，边权重含假设
- 你可以改参数、改假设、重新跑——MIT协议，代码开源
- 不说"因为A所以B"，只说关联、同步、结构提示
