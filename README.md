# 博罗县产业决策风洞

> 广东首个千亿县，在大湾区网络里是什么位置？

基于城市计算与复杂网络的区域决策风洞，以广东省惠州市博罗县为样本。
这是「风洞系列」的第四个样本：大亚湾（物的管廊）→ 仲恺（企业链）→ 惠城（人—产业—城）→ **博罗（在大湾区网络里占位置）**。

不是预测器，不是数据大屏，不是 PPT——是一台把不确定性变成可拍板结构的机器。

## 这台风洞最想让你看到的

- 2025 年博罗 GDP 刚过千亿（1005.45 亿），但房地产投资 −47.6%、固投 −18.8%——**跌得最响的，未必是对全局传导最强的**。
- 一万次模拟跑下来，最敏感的不是房价、不是外贸，而是**新投产项目的节奏**：投产延后两年，达标概率明显下台阶。
- 博罗的底气不在"补短板"，而在区位：20 分钟到东莞石龙、30 分钟到深圳、罗浮山每年上千万客流、近 40 万农村人口的特色农业。
- 所有结论都是"结构提示"，不是预言——参数公开，你可以改、可以复跑。

## 核心数据（2025 年，全部来自公开统计公报）

- GDP：1005.45 亿元，+5.5%（广东首个千亿县）
- 三次产业结构：10.7 : 54.6 : 34.7
- 规上工业增加值：+8.7%；电子信息产业 +23.0%
- 社消零：296.99 亿，+3.9%
- 固定资产投资：−18.8%；房地产投资 −47.6%
- 常住人口：123.94 万，城镇化率 60.19%
- 年游客：1028 万人次，旅游收入 51.88 亿（人均约 500 元）
- 2030 参考目标：GDP 1600 亿（县委书记访谈提出，非刚性指标，用于情景推演）

## 技术与可复现

- 全部为静态 HTML + 原生 JS + ECharts，无后端、无数据库
- 随机种子固定，同一种子必复现同一结果
- 五条路的预期值与波动区间、全局扰动、蒙特卡洛次数均在页面上公开
- 数据血统分级：实测（统计公报）/ 推估 / 假设，不混淆

## 方法论边界

- 不是预测器，不预测博罗 2030 年的具体数字
- 所有模拟结果均为"在当前假设参数下的参考区间"
- 网络结构由作者根据公开主体与关系构建，边权重含假设
- 只说关联、同步、结构提示，不说"因为 A 所以 B"
- 你可以改参数、改假设、重新跑——MIT 协议，代码开源
