# 柏塘茶产业公开情报快照 · 2026-11-01

这一轮检索用于改变“先查什么、先试什么”的顺序。`tea-intelligence.js` 是页面与导出共用的结构化快照，包含来源、主体、关系、竞争解释、口径冲突和历史服务线索；不依赖实时搜索接口。原博罗资料库保持原样。

## 当前最值得追的关键

优先拿到一位真实买方的验收规格和样品反馈。产业园的B端方向、技术落地安排与深圳侧行业合作共同提示：从流量到持续订单之间，可能先缺一个能把品质、批次、交期和责任接起来的工作环节。这是推断，不能由此说当地产品不合格或所有企业都缺人才。

培训已有资源线索：2026年8月的地方发布记录了协会签约和AI营销课程捐赠。下一步应追具体执行、作品与经营反馈；签约、赠课和结课都不能替代订单或学员能力证明。学校团队在本版是待建设的角色，没有编造已参与学校。

茶旅场景可沿“试饮、买茶、后续再买”继续调查。小茶园使用本地山茶的报道提供了产品到场景的联系，但无法识别具体供茶方；没有把同处柏塘或同一品牌下的项目连成未经证实的采购链。

## 如何使用碎片

1. 优先参与方发布和官方目录；采访报道保留其报道范围。转载线索附原链接与核验状态，不当成已经确认的机会。
2. 关系分为原始记录、报道、编目线索、待核转载和本版假设。共同起草标准只说明编目协作，不推导供销、股权或当前订单。
3. 对每个问题同时保存其他解释与改变判断的证据。“没查到”只指本次检索未取得，不等于不存在。
4. 同文转载按 `origin_group` 归为一个来源事件；不同媒体引用同一镇级统计也不意味着独立实测。
5. 设计量、报道实际量、按单价估算值、历史许可与未来意向分别记录。没有用冲突总量校准原承接试验。

## 必须保留的三处差异

- 2025年产量与产值：南方日报报道2449吨、约12亿元；羊城晚报报道2570吨、12.8亿元，后者注明单价测算。缺少统计底表时不平均、不推算增长或企业份额。
- 旧省级标准已废止，但另有现行市级标准DB4413/T 6-2019，2024年复审表列继续有效。不能把旧标准的废止解释成没有标准。
- 58家茶企合作社与含酒店文旅的65家协会整合成员不是同一总体；30万斤为一个厂的设计干茶加工量，不是全镇实产，也不是当前可用余量。

## 新证据到来以后

页面用样品、供货、复购三个可区分原因的问题演示更新判断：样品未被接受先追拒收原因；供货不稳先定位断点；验收与供货稳定但未复购时，降低“先补品质供货”的优先性，转查需求、价格和渠道。它不是拟合后的因果模型，没有给出成功概率。

用户填写的现场情况与备注只作为用户观察，保存在本地记录和分享状态中，不会改写公开快照。应在备注写明产品、买方、时间、样本与依据。正式研究仍需访谈、业务台账和观察周期。
