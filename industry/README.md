# 博罗产业工作区

独立入口：`/boluo-simulator/industry/`。只新增本目录，不修改原首页、全息页、全县 GDP 模型、每日数据或工作流。

## 这版能做什么

- 选择茶、电子信息、新能源、文旅住宿或特色农业，进入相应的关系与事件资料。
- 茶产业提供完整操作样板：关系探索、节点拖动与聚焦、查看已登记事件、独立条件试验、比较可选支持、记录核实事项、保存／恢复／分享／导出与导入。
- 通过 URL 还原行业、节点、事件、输入条件和核实进度。页面切换不恢复默认参数。
- 原有完整页面均可从“全县视图与完整内容”打开。

## 资料与假设

资料优先读取原库 `../data/relationship-{evidence,sources,changes}-v1.json`，展示原库登记时间；读取失败则使用内置的有限茶产业资料快照。不把快照称为当日数据，不声称本版重新核验了全部来源。

茶产业图中的加工、包装、品牌、电商等是明确标注的机制角色，具体主体与交易关系待补。可选支持为待核实的角色方向，并非已确认供应商或合作推荐。其他行业的节点和关系取自原库，当前没有对应行业的数值推演。

`engine.js` 是独立的串行承接与等待试验，不调用或改变 `../model.js`。默认每期100份假设订单、加工125份、包装115份、发货130份，连续4期；全部可以替换。±波动范围用于组合假设、给出条件下的结果范围，不是实测置信区间或现实成功概率。模型不涉及真实价格、利润、复购预测或企业经营承诺。

增补支持的30份／期为界面明确展示的假设增量，不代表候选企业的产能。加工、包装、发货依次守恒，补一环可能将瓶颈移到另一环。没有将县域 GDP 换标题充当行业模型。

## 检查

```sh
node --check industry/app.js
node --check industry/data.js
node --check industry/engine.js
node industry/tests/engine.test.cjs
```

观察记录只存当前浏览器。清除浏览器数据会移除记录，请按需导出 JSON 备份；分享链接携带当前情景与核实进度，不包含记录列表。无登录、无消息发送、无自动撮合。

茶叶图片为生成的视觉示意，不宣称拍摄于某一真实茶园。
