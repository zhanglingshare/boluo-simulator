# 博罗完整通俗版（与专业原版并存）

**主入口：** https://zhanglingshare.github.io/boluo-simulator/easy/

这是博罗风洞原有用户页面的 **完整保留版**。要求：内容不减少，只降低语言门槛。原有数据、模型、图表、全部段落、互动和详细报告都保留。

## 完整版页面

`easy/full/` 下已经为以下13个用户页面建立了原样副本：

- `index.html` 今日博罗
- `holo-home-v10.html` 变化现场和全息关系
- `town.html` 各镇吃喝玩乐
- `network.html` 产业关系世界
- `who.html` 博罗基本面
- `choices.html` 五条发展路线
- `future.html` 2030年未来推演
- `windtunnel.html` 风洞压力测试
- `blindspot.html` 忽略了什么
- `report.html` 完整分析报告
- `ending.html` 结语
- `role.html` 角色体验
- `lab.html` 深入实验

这些副本以当时原页面全部HTML内容为基础，不删原有段落和脚本，仅增加资源路径适配、通俗话说明条与脚本。`easy/plain.js` 只在页面显示层翻译已核对的术语，保留原术语在括号中；用户可以点击“看原话”切换回来。模型计算继续读取原版同一份 `model.js`，其他资源仍取原仓库。

## 非默认的小游戏

- `easy/game.html` 是原先的10站轻量互动和5关小游戏，现为**可选练习**，不得替代完整内容。
- `easy/index.html` 的默认入口现在是13个原样页面的导航，而不是闯关缩略版。

## 两条底线

1. 不要改动或覆盖专业原版 `index.html`、`holo-home-v10.html`、`model.js` 等任何现有页面或底层模型。
2. 不要以简化为借口删掉图表、数据、证据链、变量、结果分布、敏感性、详细文字、科研口径和交互。每次有新内容更新，应同步到对应的完整版副本，并复核通俗解释是否准确。

## 验证范围

每个副本与原版代码做过全文对比：除明确新增的3个注入点（`<base>`、`plain.css` 与 `plain.js`）外，其余内容保持完全相同。

自动化静态检查可验证HTML与脚本语法；**实际手机端布局、动态关系图与操作流程仍需真实浏览器回归测试**。翻译层目前先覆盖高频专业词和逐页引导，不应宣称每一段话都已人工改写完成。
