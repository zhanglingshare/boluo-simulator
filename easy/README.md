# 博罗风洞·大众版（easy/）

这是博罗风洞 **独立的大众体验版**。入口：`https://zhanglingshare.github.io/boluo-simulator/easy/`。

## 10个互动画面
通过顶部导航在 `index.html#page=...` 切换，不复制原版的十套模型：

| 入口 | 独立画面 | 主要操作 |
|---|---|---|
| `home` | 今日博罗 | 身份切换、2026变化、最近话题 |
| `change` | 变化现场 | 事件选择、前后切换、关系主体点击、12道猜题 |
| `money` | 钱从哪来/钱去哪了 | 产业占比、指标切换、100元去向小游戏 |
| `trip` | 去哪玩 | 12镇卡片、收藏、与朋友分享想去的地方 |
| `paths` | 五条路 | 五个开关、重新计算模拟结果 |
| `future` | 未来 | 计划兑现与现状延续两套情景对照 |
| `wind` | 风洞 | 三个合理范围滑块、原模型重算 |
| `blind` | 可能忽略了什么 | 5张反直觉卡，点击展开 |
| `report` | 我的发现卡 | 生成带假设说明的个人发现卡、复制与分享 |
| `end` | 最后一站 | 复盘、再次探索、分享 |

## 独立性
- **不修改**原来的 `index.html`、`holo-home-v10.html`、`model.js`、其他页面及数据。
- `site.css` 和 `site.js` 只影响 `easy/`。
- HTML入口仅加载本目录的样式/逻辑、以及原版只读的 `../model.js`。
- 读取原仓库的 `hot.json`、`life.json` 和 `data/relationship-{evidence,changes,sources}-v1.json`；原数据更新后刷新页面可重新获取。
- 2030运算只调用共享内核的 `HT.run()`；五条路和滑块改变的是明确范围内的**情景假设**，不是改写事实。没有数据时不伪造输出。
- 2025 GDP 1005.45亿元来自统计公报，1600亿元是2030参考线，**不是确定预测**。
- 2026年签约、在建、投产和已发生事件分开表述；关系不直接等于因果。
- “分享给朋友”依赖浏览器原生分享/复制，静态网站**没有**真实多人在线票数、登录、留言或服务端排行榜。

## 修改注意
保持对五年级读者友好的短文案、关键数字优先、移动端优先；不要把假设写成已发生、把模拟比例写成现实概率。新版本必须保留原版入口以及一键返回原版。

## 发布
提交 `easy/` 内文件后，使用现有 GitHub Pages 工作流发布。未经完整可视化验收，不把静态代码检查当成真实手机的布局验收。
