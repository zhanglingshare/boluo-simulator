# 博罗2032 · 公开研发Demo（完全免登录）

**入口：https://zhanglingshare.github.io/boluo-simulator/lab-2032/**

本目录是**独立公开研发体验**，没有修改既有博罗V11页面。开发阶段任何人都可以打开网页使用Demo，无需用户账户、邀请码或访问令牌。

## Demo的真实性边界

- 2025年三次产业增加值采用公开参考值（107.44、549.01、349亿元），正式研究使用前须再次核对统计来源与口径。
- 2020—2024年的历史回溯采用合成序列。
- 内置500家企业、300份制造业企业模拟问卷、250条劳动者记录、680条产业联系、30个项目。
- 以上模拟企业、调查、采购联系和项目不是现实博罗调查结果。
- 2032年结果来自显式年增长假设与扰动条件，属于演示模拟，**不等于2032年经验预测或达标概率**。
- 程序侧调查分析是**合成构念得分的标准化回归与Bootstrap**，不是与SmartPLS等价的PLS-SEM实现。

## 能做什么

1. 选5个发展情景、5个调整条件，运行实际浏览器端2,000次条件模拟，比较三次产业结构及经济总量P10/P50/P90。
2. 观察合成采购关系中的行业连接和服务需求，报告有效/失配关系的数量。
3. 对合成调查运行程序探索性路径分析及重抽样区间。
4. 下载包含6种CSV、变量字典和专业软件输出JSON模板的ZIP分析包，自行在SPSS、SmartPLS中运行。
5. 使用真实软件实际运行之后，上传其结果JSON，在浏览器中查看差异；**不得将不同算法的数值差异视为算法等价性认证**。
6. 在浏览器本地导入UTF-8 CSV替换单个数据模块并重跑情景；导入后清晰标记为`MIXED_UNVERIFIED`，不上传服务器。
7. 导出本次实验结果、假设及运行条件JSON。

## 技术边界

本目录是由GitHub Pages托管的静态网页，所有Demo计算运行于访问者本地浏览器。**没有共享数据库、服务端的真实数据建模API、生产级认证或跨设备存储**。刷新页面会恢复默认Demo。

从科学角度，简单的增长情景不能推断真实政策影响；同样不能用问卷路径系数直接折算GDP。页面提供的是开放开发阶段的验证体验，未来需由独立研究底座执行严谨的参数校准、模型检验与授权数据处理。
