**第二页数据口径：** 2025年博罗工业增速、投资、行业占比、民营/规模结构、创新指标来自公开统计公报的网络转录，原始公报仍应进一步核对；2024年博罗、惠东、鹤山、四会采用可追溯公开资料。所有交互仅筛选、比较公开事实，不通过不可靠的行业增速换算工业增加值绝对金额，更不把合成企业网络伪称现实。页面内部提供逐项来源链接。


**第三页数据口径：** 2025年GDP 1005.45亿元、三次产业增加值和结构来自2025年统计公报转录；2026年前三季度GDP及分产业增加值、增长速度来自博罗县统计局运行数据的南方+报道。2025年各产业增加值绝对额按现价，增长速度按不变价。2026年前三季度是累计数据，不与2025全年直接比较。2032年1:5:4仅为研究参考，不是正式批准的规划指标，不据此生成2032产业金额。服务业内部的增加值、营业收入、商品销售额、营业额和旅游综合收入分别标注，不混算。
**第四页数据与研究边界：** 默认使用已有830家合成企业及相应有向关系，图中的行业汇总边是从当前关系表实际聚合而来，局部主体视图是从当前数据集中提取的邻接子图，并非博罗的真实企业网络。源节点到目标节点的方向取决于关系类型，不能将所有箭头统一理解为采购方或供货方。调整冲击幅度后，调用原有`BoluoEngine.propagate`三步演示模型，仅输出示意受影响节点，不能转换成实际经济损失或政策因果效应。上传客户关系数据时，来源状态保持待核验，允许混合使用，但不伪称全网真实。

**第五页证据与计算边界：** 2026年前三季度博罗第三产业增加值增长1.2%、交通运输仓储邮政业增长7.7%、租赁商务服务业增长5.5%，均为公开统计的实际增速，可作为真实信号，但无法推断本地服务承接率。页内工业/农业与服务细分行业关系矩阵严格由当前企业主体ID和指定有向关系类型计算；默认合成数据、关系权重单位百万元。热力图零格子表示当前样本未记录，不等于现实中没有交易。筛选关系权重前25%/前10%时，未显示的低权重记录不代表缺少交易；情景实验使用与矩阵相同的筛选范围。供需压测只是在当前关系权重基准上施加人工需求和承接增幅，基准不是服务产能或真实需求，结果不能等同博罗缺少的GDP。反馈记录留在当前浏览器会话，允许导出JSON，但未经核验绝不升级为A级数据。参见页面内统计来源和方法说明。

**第六页数据与计算边界：** 2025博罗全县第一产业增加值107.44亿元、实际增长7.8%；2026年一季度农林牧渔业总产值36.03亿元、增长6.5%，口径不同不可混算。柏塘2025茶叶总产量约2449吨、茶叶总产值约12亿元、茶园面积约4.32万亩、茶企与合作社58家，均为2026年媒体引述的镇域产业信息，未经部门原始数据再次核验，不可充当全县GDP或农户净收入。研究案例中的25天采摘窗口、12天农户收款、75天渠道回款均为需要客户确认的演示假设；没有证据证明它们是柏塘真实平均账期。逐日现金占用模型使用可调的每日采购基准和劳力/加工比例，在有限季节内逐批付款与回款。默认的峰值占用212.5万元（25天、每日10万元、劳力85%、加工90%，付款第12天/回款第75天），并非63×10万元；它是纯条件演示而不是实际融资需要。农业加工和流通关系统计使用当前数据ID与有向关系类型，默认合成主体与合成交易；用户导入资料会保持待核验标识。现金流实验与数据核验清单可导出JSON，数据不上传服务端。

## 首次使用

1. 打开主页，不需要任何访问令牌。
2. 查看“目标与现实”，然后选择“2032风洞”，修改增长条件观察真实重新计算的产业结构和分布；不是预制结果。
3. 在“数据中心”导入宏观、企业、关系、调查、项目或劳动者的CSV/XLSX/JSON，匹配字段后创建新的研究快照。仅在你的浏览器内存处理；并不上传到GitHub。
4. 在“行业结构”“镇街比较”“产业网络”“项目接续”“就业与人才”检查新数据能否支持对应分析。
5. 在“双轨模型实验室”运行程序模型，同时下载完整ZIP分析包，用SPSS/SmartPLS实际运行，再导入外部估计结果的JSON进行初步对照。
6. 在“压力与敏感性”和“行动方案”构造对照情景。
7. 在“研究报告”导出研究成果及完整研究快照。由于静态网页不保存个人研究数据，刷新前请导出快照，以便以后恢复。

## 数据规范与诚实边界

**Demo V2默认生成以下合成研究数据：**

- 2020—2024年度三次产业合成回溯；2025年宏观采用公开参考值107.44 / 549.01 / 349.00亿元（使用于正式研究前仍须核对原始统计来源和口径）。
- 830家合成农业、制造和服务主体（并不代表博罗实际企业名册）。
- 由合成主体ID连接的模拟服务采购、工业采购、农业加工与流通关系。
- 420份模拟企业问卷、420条模拟劳动者记录、72条合成项目。

**宏观增加值、企业营业收入、交易金额和投资金额是不同计量口径，不可相加。** Demo包含简化名义增长情景，并不能证明2032年真实增速、产业关系或任何政策效果。2032年1:5:4是研究参考线，不是预置正确结果。

**程序模型与专业软件不同。** 现有程序侧提供可运行的探索性Mode-A PLS路径实现和构念得分回归，尚未建立与商业SmartPLS逐项等价的实证验证；AMOS/CB-SEM等完整专业估计需通过专业软件另行执行。上传真实软件结果后只是数值对照，不能伪称已通过等价认证。问卷路径系数不得直接转换为GDP增加值或政策因果效应。

**接入真实数据不等于验证完成。** 系统对导入部分标识 `IMPORTED_UNVERIFIED`，逐个模块记录来源，混合研究保留`MIXED_UNVERIFIED`标签。数据质量、统计口径、授权与样本代表性仍需研究者审核。

## 工程结构

- `studio.html`、`studio.css`、`studio.js`：完整版工作台
- `industry-2025.js`、`industry-2025.css`：第二页公开工业统计的交互可视化
- `base-structure.js`、`base-structure.css`：第三页真实经济底盘、结构对照、年度GDP年轮、2026前三季度观察和证据缺口
- `relations-experience.js`、`relations-experience.css`：第四页产业连接、局部主体网络、筛选、断点实验与数据来源状态
- `service-bridge.js`、`service-bridge.css`：第五页服务业增速信号、双产业关系矩阵、条件性缺口实验、本地勘误和JSON导出
- `agri-value.js`、`agri-value.css`：第六页真实统计案例、农业四环节、可复现逐日现金流、关系证据及核验任务导出
- `core.js`：统一合成数据及CSV/XLSX/JSON本地接入
- `engine.js`：产业、网络、项目、调查、PLS、情景及压力计算
- `tests/full_browser.py`：逐项验证19个工作区、真实计算、CSV/XLSX、专业分析ZIP、研究报告、桌面与手机
- `quick-demo.html`、`app.js`、`style.css`：保留的初期四工作区示例

完整版为公开、免登录、仅浏览器本地计算的开发版本。它**不是已经部署了服务器端数据库、并发计算、生产级权限控制或政府统计实时接入的系统**。涉及规模较大的、需持久保存的或有敏感性限制的真实部门数据，应使用独立受控环境，而不能依赖静态网站。
